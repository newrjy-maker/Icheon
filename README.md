# 이천 모험지도

이천을 방문하는 만 3~10세 자녀 동반 가족을 위한 현장 QR 퀘스트형 모바일 웹 디자인 프로토타입입니다.

## 핵심 경험

- 개인정보 없이 서비스 전용 아이디 하나로 가입하고 진행 상태 복원
- 호법JC를 중심으로 동·북·서·남 4개 테마 지도를 비교해 시작
- 각 지도에서 차량 10분 이내로 연결된 현장 QR 퀘스트 3곳을 `1→2→3` 순서로 진행
- 퍼즐 `3/3` 완성 시 차량 30분 이상 떨어진 비밀맵 해금
- GPS 자동 인증 없이 협력 관광지의 현장 QR만 사용

## 디자인 미리보기

Node.js가 설치된 환경에서 다음 명령을 실행합니다.

```bash
node design/preview-server.cjs
```

브라우저에서 다음 주소를 엽니다.

- 전체 시안: <http://127.0.0.1:8000/design/drafts.html>
- 호법JC 4방 메인 허브: <http://127.0.0.1:8000/design/01-home-hub.html>
- 예스파크 스팟 상세: <http://127.0.0.1:8000/design/03-spot-detail.html>
  - 정상 운영: <http://127.0.0.1:8000/design/03-spot-detail.html?state=open>
  - 오늘 휴무: <http://127.0.0.1:8000/design/03-spot-detail.html?state=closed>
  - 검수 필요: <http://127.0.0.1:8000/design/03-spot-detail.html?state=review>

## 주요 화면

1. 도자기 인트로
2. 퍼즐 조각 맛보기
3. 개인정보 없는 모험가 회원가입
4. 호법JC 4방 메인 허브
5. 방문 스팟 상세 및 검수 상태
6. 현장 QR 인증 및 보상
7. 지도 완성·비밀맵 해금
8. MY 지도 이어하기

공개명은 **이천 모험지도**이며 기존 만화·게임 IP를 사용하지 않는 오리지널 디자인입니다.
